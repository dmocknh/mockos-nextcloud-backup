MockOS Nextcloud Backup

A personal backup utility that copies the owner's Nextcloud files, database backup, and application configuration to the owner's Google Drive using rclone.

This app is for the owner's private use. It is not a public file-sharing service and does not offer sign-in to other users.

The Google Drive connection allows the utility to read, create, update, and remove backup files. Older versions are retained according to the configured backup policy.
