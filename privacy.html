Privacy policy

MockOS Nextcloud Backup · Updated October 7, 2026

Purpose and data use

This personal utility uses rclone to back up the owner's Nextcloud files, database, and application configuration to the owner's Google Drive. It reads file contents and metadata, uploads backups, verifies stored copies, and manages backup history.

Google Drive access

The utility requests Google Drive read/write access because it must maintain an existing backup folder. That permission can access files across the authorized Drive account; the configured backup job operates within its designated backup folder. It does not make backup files public or change their sharing settings.

Storage and disclosure

Backup copies are stored on the owner's server and in the owner's Google Drive. Connection credentials are stored in restricted configuration files on the owner's server. Google processes the stored files under its own terms and privacy policy. This app does not sell data, use it for advertising, or use it to train AI models.

Retention and control

Backups and older versions follow the owner's configured retention policy. The owner can stop the backup job, remove stored backups, or revoke this app's access in Google Account settings. Revoking access stops future transfers but does not remove copies already stored.

Limited use and contact

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

For questions, contact the app owner. This information site contains no backup data or connection credentials.
